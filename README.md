# Claude Alfred Workflow

A silly workflow to generate short responses in a playful way using Claude. I use it to respond to my coworker's daily "good morning" in Teams.

## Features

- Takes the selected text as input
- Uses the Claude API to generate a response in one of several "voices"
- Copies the response and pastes it (back to Teams)

## Setup

1. Install the workflow in Alfred
2. Create `.anthropic_key` containing your Anthropic API key with no whitespace or newlines
3. Install the dependencies:

```bash
pip install -r requirements.txt
```
